Alpha Service Profitability Analysis

Power BI portfolio project comparing monthly profitability of Colocation and Cloud from user-provided assumptions. See the project files for the Excel workbook, Power BI-ready CSV data, DAX measures, model and dashboard blueprint, and Persian executive report.

Key monthly results (million Toman): Colocation revenue 1,850, cost 1,480, profit 370, margin 20%; Cloud revenue 1,000, cost 600, profit 400, margin 40%; combined revenue 2,850, cost 2,080, profit 770, margin 27.0%.

All 10 Colocation racks are assumed billed; all 200 Cloud VMs are assumed sold as specified. PeriodStart=2026-10-01 is a sample reporting month, not a claim of an actual transaction period. Taxes, depreciation, capex, finance costs and unspecified overheads are excluded. A native PBIX is not generated; the repository includes DAX and the blueprint for Power BI Desktop.
